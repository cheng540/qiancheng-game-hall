# 千城游戏厅

网页游戏聚合平台：接入 35 款 H5 小游戏，自研用户系统、好友/收藏/战绩档案、管理后台，线上有真实用户运行。

## 自研部分

- **server.js**：Node.js 服务端——注册登录（盐值+SHA-256 加盐哈希、token 会话）、用户数据存取、公告系统、数据接口
- **platform/**：自研对战与休闲游戏（斗地主、三消、派对玩法等），含客户端逻辑、对战引擎（engines.js）、管理端（admin.js）
- **frames/**：段位/评级框素材（S/A/B/C）
- **admin.html**：管理后台（公告、用户、数据）

## 用户系统设计

- 密码不明文存储：注册时生成随机 salt，存 SHA-256(salt+password)，登录下发随机 token
- 档案数据（好友、收藏、对局历史、赛季）与账号分离存储
- 线上运行数据（用户档案、日志）不入库，仓库只含代码与结构

## 运行

```bash
npm install
node server.js   # 默认 80 端口
```
